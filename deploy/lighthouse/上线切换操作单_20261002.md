## 三、DNS 切换操作（DNSPod，最后一步）

**入口**：腾讯云控制台 → DNSPod → 我的域名 → `tdyylung3d.cn` → **解析**

**第 1 步 —— 预先调小 TTL（可选但推荐）**
把 `@` 那条记录的 TTL 先改为 **600 秒**，等一个旧 TTL 周期后再执行第 2 步（便于快速回滚）。

**第 2 步 —— 改写记录**
找到这条记录并**直接修改**（不要新增，`@` 不能同时存在 CNAME 与 A）：

| 字段 | 原值 | 改成 |
|---|---|---|
| 主机记录 | `@` | `@` |
| 记录类型 | `CNAME` | **`A`** |
| 记录值 | tdyylung3d.cn.tcbaccess.tencentcloudbase.com | **`82.156.160.22`** |
| TTL | 默认 | 600 |

**第 3 步 —— www（可选，二选一）**
- 想让 `www.tdyylung3d.cn` 也能开：新增 A 记录 `www` → `82.156.160.22`
- 不需要 www：把 www 已有的解析**删掉**（备案核查要求"主域名和 www 都要能正常打开"，两者留其一需自洽）

**第 4 步 —— 证书（首次上线）**
- 先用项目里已有的 TrustAsia 证书（`tdyylung3d.cn_nginx/`，crt 与 key 已验匹配，**有效至 2026-11-30**）先把 HTTPS 跑通；
- 待 DNS 已指向本机、80 端口可达后，再用 `acme.sh`（DNS-01 + DNSPod API，或 HTTP-01）改为自动签发 + 自动续期。
- ⚠️ 注意先后顺序：HTTP-01 校验需要通过 80 端口访问本机，必须**先切 DNS 再签发**；不想等就先用现有证书顶一段。

## 四、切换后验证清单

```bash
# 1. 解析是否已指向轻量
nslookup tdyylung3d.cn          # 期望 A 记录 = 82.156.160.22

# 2. 健康检查
curl -sS -m 15 https://tdyylung3d.cn/api/health

# 3. 确认不再是云托管（响应头不应再有 x-cloudbase-*）
curl -sI -m 15 https://tdyylung3d.cn/api/health | grep -i -E "server|x-cloudbase"

# 4. 首页可达 + 备案号已悬挂
curl -s -m 15 https://tdyylung3d.cn/ | grep -o "陕ICP备[0-9]*号-[0-9]*"

# 5. 端到端：上传一个 nii.gz → 轮询 /api/case/{id} → 下载 /api/mesh/{id}/*.glb

# 6. 证书有效期
echo | openssl s_client -connect tdyylung3d.cn:443 -servername tdyylung3d.cn 2>/dev/null | openssl x509 -noout -dates
```

## 六、切换后遗留待办

1. **公安备案**（若尚未办完，切完仍要补）
2. **证书自动续期**：`acme.sh` 定时任务 + 到期前自动 reload nginx
3. **数据备份**：轻量本机盘解决了持久化，但仍需定期备份（快照 / 异地拉取）

5. **进程守护与监控**：容器 `restart: unless-stopped`、日志轮转、磁盘/内存告警
6. **git 收尾（P0）**：`git rm -r --cached web_output`；提交 miniprogram 7 个 + web 2 个未提交文件
