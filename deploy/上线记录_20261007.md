## 四、本轮打通的关键能力：小程序 CLI 上传通道

此前多轮尝试都卡在「工具的服务端口已关闭」，本轮定位并解决。

**根本原因**：开发者工具的 CLI 服务端口开关存在本地存储里，默认关闭；
`cli.bat` 的 `y` 确认需要真实 TTY，管道输入无效（`winpty` 也不行）。

**开关存储位置**

```
%LOCALAPPDATA%\微信开发者工具\User Data\<用户哈希>\WeappLocalData\
  ├─ localstorage_b72da75d79277d2f5f9c30c9177be57e.json   ← 键名 reduxPersist:settings
  └─ ls_b72da75d79277d2f5f9c30c9177be57e.json             ← 同上（镜像副本）
```

对应字段（改完需**启动 IDE** 才生效，IDE 启动时读取）：

```json
"security":{"enableServicePort":true,"port":3799,"allowGetTicket":false,"trustWhenAuto":false}
```

**另一个坑**：Git Bash 里用 `cmd //c start "" "<含中文的 exe 路径>"` 启动 IDE 会因编码错乱**静默失败**
（进程根本没起来，只在首次尝试时把 `.cli` 写成默认端口 3799，容易误判成"已开启"）。
改用 PowerShell 的 `Start-Process` 才能正确拉起。

**成功后的调用方式**（路径含中文时建议用 PowerShell 调用）：

```powershell
& "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" islogin
& "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload `
  --project "C:\Users\wangl\Documents\.opencode\肺结节重建及查看软件\miniprogram" `
  -v 1.2.1 -d "备注"
```

**安全提示**：`enableServicePort` 会让 IDE 在 **127.0.0.1** 上开一个可被本地进程调用的服务端口
（本轮为自动分配端口 `60860`）。若不再需要 CLI 上传，可改回 `false`。
改动前的配置已备份至：
`C:\Users\wangl\AppData\Local\Temp\wxdevtools_cfg_bak_20261007_222629\`
