### 小程序码 40066：已定位并修复

**根因不是页面路径**。对照实验（`getwxacodeunlimited`）：

| 组合 | 结果 |
|---|---|
| release + `pages/viewer/viewer` | 40066 |
| release + `pages/index/index` | 40066 |
| release + **不带 page** | 40066 |
| trial / develop + viewer | 40066 |
| **`getwxacode`（限额接口）+ path** | ✅ 正常出图 |

即：**小程序没有正式发布版本**时，`getwxacodeunlimited` 整类不可用，与 path 无关。

修复（`lung3d_api.py` `/api/wxacode`）：先试 unlimited，失败自动降级到
`getwxacode` + `path=pages/viewer/viewer?c=<case_id>`。前端 `viewer.js` 的
`resolveCaseId` 本就优先读 `options.c`，所以**小程序无需重新上传**即可直达。
响应头 `X-Wxacode-Mode` 标明实际用的接口（`unlimited` / `limited`）。
顺带修了图片类型：微信 limited 返回的是 **JPEG**，按魔数标 `Content-Type`。

实测线上：`/api/wxacode?case=...` → 200、`image/jpeg`、104 KB。
