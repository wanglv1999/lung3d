## 二、Web 端 · 云托管新建版本（控制台操作）

1. 进入 **微信云托管控制台** → 选择服务 → **版本管理** → **新建版本**
2. 部署方式选 **从地址拉取镜像**，填入：
   ```
   docker.io/wlv2026/lung3d-web:latest
   ```
   > 前提：Docker Hub 仓库 `wlv2026/lung3d-web` 必须是 **public**，否则云托管拉不到。
3. 端口填 **8000**，健康检查路径 **`/api/health`**
4. 其余保持与当前版本一致（环境变量、实例数等），提交部署
5. 部署完成后观察健康检查通过，再把**流量切到新版本**
6. 验收（在浏览器无痕窗口）：
   ```
   https://tdyylung3d.cn/api/health      -> {"status":"ok"}
   https://tdyylung3d.cn/                 -> 标题 Lung3D，侧栏底部有 陕ICP备2026023325号-2
   ```

**建议同时确认的两件事：**

- **`www.tdyylung3d.cn` 能否打开**：云托管自定义域名目前只绑了裸域。若 www 仍打不开，
  要么在云托管补绑 www，要么删掉 DNSPod 里 www 的解析，避免"解析得到但访问不通"。
- **HTTPS 证书到期日 2026-11-30**，云托管不自动续期。续期方案与脚本在 `deploy/cert/`，
  已配置每周一自动巡检提醒（剩余 ≤30 天告警）。

### 3.2 公众平台配置（提审前必须确认）

| 位置 | 要确认的内容 |
|---|---|
| 开发管理 → 开发设置 → **服务器域名** | `request` / `uploadFile` / `downloadFile` 合法域名均包含 **`https://tdyylung3d.cn`** |
| 设置 → **服务类目** | 与个人主体可开通范围匹配（医疗类目个人主体通常开不了，需选工具类） |
| 设置 → **基本设置 → 小程序名称** | 保持中性（当前为 `Lung3D`，勿出现"肺""结节""诊断"等词） |
| 版本管理 → **小程序备案** | 平台要求小程序自身备案。若尚未办理，可能影响后续版本发布/上架（本次不阻塞） |

### 3.3 提交审核

1. 公众平台 → **版本管理** → 开发版本 → **提交审核**
2. 填写信息：
   - 功能页面：`pages/index/index`（数据列表页），必要时补 `pages/viewer/viewer`
   - 功能描述：**通用三维模型查看工具**，上传体数据后生成三维模型并在手机查看
     —— 不要出现"医学影像""辅助诊断""结节检出"等表述
   - 截图：使用数据列表页与三维查看页，**不要截到结构名面板**
3. 提交后审核通过 → **发布**

### 3.4 被拒时的常见应对

| 拒绝理由类型 | 应对 |
|---|---|
| 类目不符 | 调整服务类目为工具类；说明"通用三维模型查看" |
| 内容涉及医疗 | 核对截图与描述；确保无医学名词；必要时增加"通用数据查看"说明文案 |
| 缺少资质 | 个人主体无法补医疗资质，只能收敛定位为通用工具 |
| 备案问题 | 悬挂的网站备案号主体与小程序认证主体一致（个人·王律），如被质疑需说明主体一致性 |
