## 二、Web 端上线（腾讯云托管 CloudBase Run）

> **当前阻塞**：Docker Desktop 未启动；推送需仓库凭据（Docker Hub 用户名/Token 或 ccr 账号）。

### 步骤

**1. 启动 Docker Desktop**，确认 daemon 就绪
```bash
docker info
# 出现 Server Version 即正常
```

**2. 构建镜像**（在项目根目录）
```bash
docker build -t lung3d-web .
```

**3.（可选）本地验证页脚真的渲染出来了**
```bash
docker run --rm -p 8000:8000 lung3d-web
# 另开终端：
curl -s http://localhost:8000/ | grep -o "陕ICP备[0-9]*号-[0-9]*"
# 能打印出备案号 = 页脚已进镜像
```

**4. 推送到镜像仓库**（二选一）

- **Docker Hub**（用现成脚本）：
  ```powershell
  .\deploy\push_existing.ps1          # 推 :latest
  .\deploy\push_both.ps1              # 推 :stable + :latest
  ```
- **腾讯云 ccr**：
  ```powershell
  .\deploy\build_push.ps1 -Image ccr.ccs.tencentyun.com/<命名空间>/<服务名>:latest -User <用户> -Pass <密码>
  ```

**5. 云托管控制台 → 新建版本**
- 镜像：选刚推送的 tag
- 端口：`8000`
- 健康检查：`/api/health`
- 发布

**6. 线上验证**
```bash
curl -s https://tdyylung3d.cn/ | grep -o "陕ICP备[0-9]*号-[0-9]*"
curl -s -o /dev/null -w "%{http_code}\n" https://tdyylung3d.cn/api/health
```

## 三、小程序端上线

1. **微信开发者工具**打开 `miniprogram/` 目录
2. 点击「**上传**」，填版本号（如 `1.3.2`）与备注
3. `mp.weixin.qq.com` →「**版本管理**」→ 把开发版**提交审核**
4. 审核通过后**发布**
5. **验证**：微信打开小程序 → 首页底部应显示 `陕ICP备2026023325号-2`，点击应弹出「备案号已复制」

> 备案号只在 `miniprogram/config.js` 一处维护。若日后办下小程序备案号（形如 `陕ICP备2026023325号-XXA`），改这一行再上传即可。
> 把 `ICP_BEIAN` 改成 `''` 会让页脚自动隐藏（保留了 `wx:if` 条件渲染）。
