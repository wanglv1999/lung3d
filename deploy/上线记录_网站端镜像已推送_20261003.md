1. 打开**微信云托管控制台** → 你的服务 → **新建版本**
2. 部署方式选「**从地址拉取镜像**」，地址填：
   ```
   docker.io/wlv2026/lung3d-web:latest
   ```
   （Docker Hub 仓库须为 **public**；此前已推送过，说明配置没问题）
3. 端口填 **8000**，健康检查路径填 **`/api/health`**
4. 部署完成后，云托管会把新版本逐步放量；确认无误后保留新版本、停用旧版本

- 如需回到历史镜像：仓库另有 `wlv2026/lung3d-web:stable`（若历史推送存在），或按旧 digest 重新指定
