## 二、上线步骤（Web 端）

> 前置：启动 Docker Desktop（`docker info` 能看到 Server Version）

```bash
# 1. 构建（项目根目录）
docker build -t lung3d-web:latest .

# 2. 本地验一下页脚真的进镜像了
docker run --rm -p 8000:8000 lung3d-web:latest &
curl -s http://127.0.0.1:8000/ | grep -o "陕公网安备[0-9]*号"
# 能打印 = 已进镜像

# 3. 推远端（双名制：本地短名 → 远端长名）
docker tag  lung3d-web:latest wlv2026/lung3d-web:latest
docker push wlv2026/lung3d-web:latest
docker images --format "{{.ID}} {{.Repository}}:{{.Tag}}" | grep lung3d-web   # 记 IMAGE ID
```

**4. 云托管控制台（人工）**
版本管理 → 新建版本 → 镜像 `docker.io/wlv2026/lung3d-web:latest`
→ 端口 **8000** → 健康检查 **`/api/health`** → 切流量

**5. 线上验证**

```bash
curl -s https://tdyylung3d.cn/ | grep -o -E "陕ICP备[0-9]*号-[0-9]*|陕公网安备[0-9]*号"
# 期望两行都出现

curl -s https://tdyylung3d.cn/api/health
# 顺带确认 storage 段（本轮镜像同时带上持久化改造）
```
