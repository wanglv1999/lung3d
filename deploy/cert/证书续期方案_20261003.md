# HTTPS 证书续期方案（Lung3D / tdyylung3d.cn）

> 编制日期：2026-10-03
> 适用对象：线上生产域名 `tdyylung3d.cn`（微信云托管）+ 规划中的轻量应用服务器（82.156.160.22）

---

**序列号完全一致 → 线上证书 = 手动上传的这张 90 天 TrustAsia DV 证书。**

### 2. 微信云托管没有"证书自动续期"能力

微信云托管官方文档（自定义域名章节）明确写：

> 「证书过期更新，**直接「编辑」重新上传证书**，不需要删除重新配置。」

也就是说：**云托管只负责"挂"证书，不负责"续"证书**。证书到期不会自动换，必须有人上传新的。

### 3. 结论：当前状态是"裸奔"

- 线上证书 **无任何自动续期机制**
- 到期时间 **2026-11-30**，距今 57 天
- 一旦过期 → 小程序所有 `wx.request` 直接失败、Web 端浏览器红锁拦截、备案核查可能被判定异常

## 二、到期后果（为什么必须现在就安排）

微信小程序强制要求后端域名 HTTPS 且 TLS ≥ 1.2。证书过期当天：

| 影响面 | 表现 |
|---|---|
| 小程序 | 首页加载数据失败、扫码进查看器报网络错误，**用户侧 100% 不可用** |
| Web 端 | 浏览器显示"不安全"，多数用户直接关掉 |
| 备案 | 域名 HTTPS 异常可能触发核查 |
| 恢复成本 | 从发现到修好，最快也要 30 分钟（申请+上传），但**通常是用户先投诉你才知道** |

## 三、三条路线对比

| | 路线 A：腾讯云免费证书 + 自动续费 | 路线 B：acme.sh HTTP-01（轻量 nginx） | 路线 C：acme.sh DNS-01（DNSPod） |
|---|---|---|---|
| 适用阶段 | **迁移前**（云托管） | **迁移后**（轻量 nginx） | 迁移前后**都能用** |
| 签发者 | TrustAsia / Let's Encrypt | Let's Encrypt | Let's Encrypt |
| 有效期 | 90 天 | 90 天 | 90 天 |
| 自动签发新证书 | ✅ 到期前 29 天自动续费 | ✅ acme.sh cron 自动 | ✅ acme.sh cron 自动 |
| **自动部署到服务** | ❌ **仍需手动上传到云托管** | ✅ 自动装到 nginx 并 reload | ✅ 自动装到 nginx 并 reload |
| 需要什么 | 腾讯云账号 | DNS 已指向本机 + 80 通 | **DNSPod API 密钥** |
| 迁移前能否签发 | ✅ | ❌（DNS 还没切过来） | ✅ **可以提前签好** |
| 手动程度 | 每 90 天手动上传一次 | **零手动** | **零手动**（nginx 场景） |
| 国内兼容性 | 最好（TrustAsia 国内根） | 好（ISRG Root X1 兼容主流） | 好 |

### 推荐组合

```
┌─ 迁移前（现在 ~ 迁移日）─┐  路线 A：腾讯云免费证书 + 自动续费 + 手动上传
│  保险起见              │  ＋ 到期巡检自动化（本项目已配）
└────────────────────────┘
┌─ 迁移后（轻量服务器）──┐  路线 B：acme.sh HTTP-01 → 全自动，彻底免手动
│  一劳永逸              │
└────────────────────────┘
```

**如果想一步到位**：走**路线 C**。在任意一台 Linux 机器（包括轻量服务器）上用 acme.sh + DNSPod API 签好证书，产出的 `fullchain + key` 既能传给轻量 nginx，也能上传到云托管——**迁移前后一套流程，不用换工具**。

## 四、操作步骤

### 路线 A：迁移前兜底（推荐现在做）

**A1. 申请腾讯云免费 DV 证书**

1. 登录 [腾讯云 SSL 证书控制台](https://console.cloud.tencent.com/ssl)
2. 「申请免费证书」→ 填写域名 `tdyylung3d.cn`
3. 验证方式选 **DNS 验证**（域名在 DNSPod，一般可自动完成；失败就按提示加一条 TXT 记录）
4. 签发后**开启「自动续费」**（到期前 29 天自动签新证书）
5. 注意：**不要申请通配符证书**（`*.tdyylung3d.cn`）—— 微信小程序不支持通配符证书

> ⚠️ 还有一个域名 `www.tdyylung3d.cn`：它是同一张证书的 SAN 里的。腾讯云免费证书一次只能填一个域名，双域名要签两张或改用 acme.sh（路线 B/C 一条命令同时覆盖两个）。

**A2. 下载并上传到云托管**

1. 证书列表 → 下载 → 格式选 **Nginx**（得到 `.crt` fullchain + `.key`，文本格式）
2. 微信云托管控制台 → 服务 → **自定义域名** → 找到 `tdyylung3d.cn` → **「编辑」**
3. 重新粘贴/上传新的证书与私钥 → 确定
4. **无需重启服务，立即生效**（官方说明：编辑重传即可，不用删除重建）

**A3. 验证**

```bash
echo | openssl s_client -connect tdyylung3d.cn:443 -servername tdyylung3d.cn 2>/dev/null \
  | openssl x509 -noout -dates -serial
# 对比 serial 是否已变成新证书
```

---

### 路线 B：迁移后全自动（轻量服务器）

前置：DNS A 记录已指向 `82.156.160.22`，安全组放行 **80 + 443**，nginx 已按 `deploy/lighthouse/nginx/lung3d.conf` 配好。

```bash
# 在轻量服务器上
cd /opt/lung3d
bash deploy/cert/issue_cert_http01.sh
```

脚本会：装 acme.sh → 切到 Let's Encrypt → HTTP-01 签发 `tdyylung3d.cn` + `www` → 安装到 `/etc/nginx/ssl/` → reload nginx。

签发成功后 acme.sh 自动写入 cron，**每天检查、剩余不足 60 天自动续签、签完自动 reload nginx**。之后你再也不用管。

---

### 路线 C：DNS-01 提前签好（需 DNSPod 密钥）

**C1. 拿 DNSPod API 密钥**

DNSPod 控制台 → 右上角头像 → **密钥管理** → 创建密钥 → 得到 `ID` 和 `Token`
（腾讯云账号下的 DNSPod 也可用腾讯云 CAM 密钥，见 C2 备注）

**C2. 在 Linux 机器上执行**

```bash
cd /opt/lung3d
export DP_Id="你的ID"
export DP_Key="你的Token"
bash deploy/cert/issue_cert_dnspod.sh
```

- 密钥会被 acme.sh 存进 `~/.acme.sh/account.conf`（`SAVED_DP_Id` / `SAVED_DP_Key`），续期时自动复用，**不需要每次导出**
- 若报权限/鉴权失败，改用腾讯云 CAM 密钥 + `--dns dns_tencent`（设 `TC_SecretId` / `TC_SecretKey`）
- **DNS-01 不依赖 80 端口和 DNS 指向**，所以**迁移前就能签好**：签完把 `/etc/nginx/ssl/` 里的证书内容复制出来，按 A2 流程上传到云托管

## 六、回滚

证书类改动风险低，回滚只有一种情况：新证书上传后域名不可访问。

1. **云托管**：自定义域名 →「编辑」→ 重新粘贴**旧证书**（旧证书文件请先备份，见下）→ 确定
2. **轻量 nginx**：`acme.sh --install-cert` 前先把 `/etc/nginx/ssl/` 备份；异常时把备份文件拷回并 `systemctl reload nginx`

> **务必做**：上传新证书前，把当前证书与私钥另存一份到安全位置（比如本地 `tdyylung3d.cn_nginx/old/`），这是唯一的回滚凭据。

## 七、巡检与提醒

`deploy/cert/check_cert_expiry.py` 是一个无依赖的跨平台检查脚本（Windows / Linux 均可跑）：

```bash
python deploy/cert/check_cert_expiry.py                     # 检查线上+本地证书
python deploy/cert/check_cert_expiry.py --warn-days 45      # 自定义告警阈值
```

输出剩余天数、SAN、序列号；剩余低于阈值时以非零码退出，便于接监控。

**另已配置一条每週自动巡检任务**：每周一 09:00 检查 `tdyylung3d.cn` 与项目内证书的到期时间，剩余 ≤ 30 天时给出续期提醒与操作步骤。

## 八、坑位清单（都踩过或官方明说过）

1. **acme.sh 默认 CA 是 ZeroSSL**，首次用需注册账号、可能卡住 → 脚本里已强制 `--set-default-ca --server letsencrypt`（切 Let's Encrypt）
2. **HTTP-01 必须 80 端口通**，且域名已解析到本机。迁移前跑必然失败 —— 那是**预期行为**，用路线 C 提前签
3. **云托管不自动续期**，别以为开了腾讯云"证书托管"就完事 —— 托管只覆盖 CDN/CLB/EO 等腾讯云云资源，**不含微信云托管**
4. **别用通配符证书**，微信小程序不支持
5. **www 别漏**：当前证书 SAN 含 `www.tdyylung3d.cn`。路线 B/C 两个域名一条命令覆盖；路线 A 需要额外注意
6. **私钥严禁入库**：`.gitignore` 已屏蔽 `*.key/*.pem/*.crt/*.csr` 与 `tdyylung3d.cn_nginx/`，脚本产物目录也已屏蔽
7. **证书有效期不叠加**：提前 60 天以上签新证书会直接覆盖旧周期，纯浪费。到期前 30 天左右动作最合适
8. **Let's Encrypt 正在缩短有效期**（未来可能到 45 天）→ 这正是必须上自动化的理由，手工扛不住
