# DNSPod API 密钥获取指引（配合证书自动续期使用）

> 编制日期：2026-10-03
> 用途：为 `deploy/cert/issue_cert_dnspod.sh`（路线 C，DNS-01 自动签发）准备凭据
> 关联文档：`deploy/cert/证书续期方案_20261003.md`

---

## 一、为什么需要它

走 DNS-01 方式签发证书时，Let's Encrypt 会在你的域名下检查一条 `_acme-challenge` 的 TXT 记录。

- **手工方式**：每次都手动去 DNSPod 加 TXT 记录 → 无法自动续期，等于白搭
- **API 方式**：acme.sh 拿到密钥后**自动加记录、自动校验、自动删记录** → 才是真正的一劳永逸

所以需要一对 DNSPod 的 API 凭据（`ID` + `Token`），acme.sh 里对应变量名是 `DP_Id` 和 `DP_Key`。

---

## 二、获取步骤（约 1 分钟）

### 入口（两条任选）

- 直达：**https://console.dnspod.cn/account/token**
- 或：DNSPod 控制台 → 右上角**头像** → **API 密钥**

### 步骤

1. 用你的 DNSPod / 腾讯云账号登录（就是持有 `tdyylung3d.cn` 的那个账号）
2. 在「API 密钥」页面切换到 **DNSPod Token** 标签页
   - ⚠️ 注意别选到「腾讯云 API 密钥」那套 —— 两者不通用，acme.sh 的 `dns_dp` 要的是 **DNSPod Token**
3. 点 **创建密钥**
4. **名称**填一个能认出用途的，例如 `lung3d-cert-acme`（以后要吊销时好辨认）
5. 若页面出现**权限范围 / 可访问域名**选项 → 选 **指定域名**，只勾选 `tdyylung3d.cn`
   （最小权限原则：这把密钥只用来给这一个域名加 TXT 记录）
6. 点确认，页面会显示一对值：

   | 名称 | 示例形态 | acme.sh 变量 |
   |---|---|---|
   | **ID** | 一串数字，如 `123456` | `DP_Id` |
   | **Token** | 32 位十六进制字符串 | `DP_Key` |

7. **立刻复制保存** —— **Token 只在创建时显示一次，关掉弹窗就再也看不到了**（忘记只能删掉重建）

## 三、安全存放（重要）

### 三条红线

1. **不要贴进任何聊天窗口**（包括我）
2. **不要写进代码、不要提交到 git** —— 项目 `.gitignore` 已屏蔽 `.env`、`*.key` 等，但别依赖它兜底
3. **别用主账号的腾讯云 API 密钥**（SecretId/SecretKey）—— 那把能操作你整个云账号，泄露后果远大于这一对

### 推荐做法：存到服务器上的受限文件

在轻量服务器上执行（注意用**固定的同一个用户**，因为 acme.sh 的续期 cron 绑在 `$HOME` 下）：

```bash
# 1. 建一个只有属主可读的文件
install -m 600 /dev/null /etc/ssl/.dnspod-env

# 2. 写入凭据（把两处替换成真实值）
cat > /etc/ssl/.dnspod-env <<'EOF'
export DP_Id="你的ID"
export DP_Key="你的Token"
EOF
chmod 600 /etc/ssl/.dnspod-env

# 3. 以后要用时先加载
source /etc/ssl/.dnspod-env
```

> acme.sh 首次签发成功后，会**自动把这两个值存进 `~/.acme.sh/account.conf`**（键名 `SAVED_DP_Id` / `SAVED_DP_Key`），后续自动续期直接复用，不需要每次手动 `source`。所以这个文件主要是给"首次签发"和"重建环境"用的。

## 四、先自测：确认密钥有效（推荐）

**别等签证书失败才发现密钥错了**。拿到 ID/Token 后，先在服务器上跑一次只读测试：

```bash
source /etc/ssl/.dnspod-env

curl -s -X POST https://dnsapi.cn/Domain.List \
  -d "login_token=${DP_Id},${DP_Key}" \
  -d "format=json"
```

**判读**：

| 返回内容 | 含义 |
|---|---|
| `"code":"1"`，并列出你的域名（含 `tdyylung3d.cn`） | ✅ 密钥有效，可以签发 |
| `"code":"3"` / `"code":"4"` | 密钥错误或 ID/Token 输反了 |
| 提示权限不足 / 域名不在列表 | 创建时勾选的域名范围没包含 `tdyylung3d.cn`，回去重配 |

> 这个请求只是**列出域名**，不会改动任何解析记录，随便跑。

## 五、拿到之后怎么用

在轻量服务器上：

```bash
# 1. 加载凭据
source /etc/ssl/.dnspod-env

# 2. 首次签发（覆盖 apex + www 两个域名）
bash deploy/cert/issue_cert_dnspod.sh

# 3. 验证
python deploy/cert/check_cert_expiry.py
```

脚本会自动完成：装 acme.sh → 切 Let's Encrypt → DNS-01 签发 → 装到 `/etc/nginx/ssl/tdyylung3d.cn.{crt,key}` → reload nginx → 写入自动续期 cron。

**此时证书路径与已有的 `deploy/lighthouse/nginx/lung3d.conf` 完全对齐，nginx 配置一个字都不用改。**

## 六、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 忘了保存 Token | 无法找回，**删除该密钥重新创建**一个即可 |
| 找不到「API 密钥」入口 | 从 https://console.dnspod.cn/account/token 直达；或确认账号确实是该域名的 DNS 托管账号 |
| 分不清 DNSPod Token 和腾讯云密钥 | acme.sh 的 `dns_dp` 用 **DNSPod Token**（ID+Token）；腾讯云 CAM 密钥走 `dns_tencent`，脚本也支持，但**优先用 DNSPod Token** |
| 免费版能用 API 吗 | 可以。免费版有频率限制，但证书签发/续期一天最多几次调用，远不触顶 |
| 想换域名范围 | 删除重建密钥。**注意重建后要同步更新服务器上的 `.dnspod-env` 和 `~/.acme.sh/account.conf`** |

## 七、和另外两条路线的关系

| 路线 | 需要这个密钥吗 |
|---|---|
| A · 腾讯云免费证书 + 自动续费 | ❌ 不需要（腾讯云控制台自己完成 DNS 验证） |
| B · acme.sh HTTP-01（迁移后） | ❌ 不需要（走 80 端口文件校验，但**要求 DNS 已指向本机**） |
| C · acme.sh DNS-01 | ✅ **需要**（好处：不依赖 80 端口，**迁移前就能把证书签好**） |

如果你打算迁移完成后再弄证书，其实**路线 B 更省事**（不用管密钥）。选 C 的理由只有一个：**想在迁 DNS 之前就把证书准备好**，或者想避免将来 HTTP-01 因端口/防火墙问题续期失败。
