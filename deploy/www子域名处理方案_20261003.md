## 三、三条路线

| 路线 | 做法 | 生效 | 成本 | 代价 / 限制 |
|---|---|---|---|---|
| **A. 删除 www 解析**（推荐） | DNSPod → 记录管理 → 删除主机记录 `www` 的 CNAME | 秒级 | 0 | 不再有 www 访问；备案（域名是 apex）与小程序均不受影响 —— 已确认 |
| **B. DNSPod 显性 URL 转发** | 把 www 的 CNAME 换成记录类型「显性URL」，记录值 `https://tdyylung3d.cn` | 约 10 分钟 | 0（免费版含 2 条 URL 转发，占用 1 条） | ① 转发前地址官方仅支持 HTTP，HTTPS 需在 DNSPod 控制台「一键申请免费 SSL 证书」，申请后需实测 ② 前后两个域名都须备案（本条件已满足）③ 走的是 DNSPod 的转发服务器，非自有服务器 |
| **C. 轻量服务器承接**（正解） | 迁移完成后，把 www 的 CNAME 改为 A → `82.156.160.22` | 随迁移 | 0 | 依赖轻量迁移先完成 |

### 路线 A 执行步骤（已确认执行）

**方式一：控制台（推荐，约 30 秒）**

1. 打开 <https://console.dnspod.cn/dns/list>（或 腾讯云控制台 → DNS 解析 DNSPod）
2. 选择域名 `tdyylung3d.cn` → 进入「记录管理」
3. 找到 **主机记录 = `www`** 的那条 CNAME → 点「删除」→ 确认
4. 顺手看一眼记录列表：是否还有其它多余子域（如 `*` 通配、`test`、`dev`、临时验证记录），一并清理

**删除还是暂停？**

- **删除（推荐）**：记录不再存在，状态最干净。将来要恢复就是重新加一条记录（本来迁移后也要改成 A 记录，没有额外成本）。
- **暂停（想留后路时）**：一键停止解析，可一键恢复；但记录仍留在列表里，属于"保留了悬空配置"。

> 注意：**只动 `www` 这一行**。`@` 与 `_dnspod` 不要碰。

**方式二：API（已配好 DNSPod Token 时）**

```bash
# 1) 先查 record_id：在返回的 records 数组里找 name 为 www 的那条，取它的 id
curl -s https://dnsapi.cn/Record.List \
  -d "login_token=${DP_Id},${DP_Key}" -d "format=json" \
  -d "domain=tdyylung3d.cn" -d "sub_domain=www"

# 2) 删除：把 <RECORD_ID> 换成上一步查到的 id
curl -s https://dnsapi.cn/Record.Remove \
  -d "login_token=${DP_Id},${DP_Key}" -d "format=json" \
  -d "domain=tdyylung3d.cn" -d "record_id=<RECORD_ID>"
```

密钥获取见 `deploy/cert/DNSPod密钥获取指引_20261003.md`；返回 `"code":"1"` 即成功。

**验证（删除后）**

- 等 TTL 生效（**记录 TTL = 600s**，即 10 分钟），之后：`nslookup www.tdyylung3d.cn 8.8.8.8` → 应返回 **无地址 / NXDOMAIN**
- 换公共 DNS 复核：`nslookup www.tdyylung3d.cn 223.5.5.5`
- Windows 清本地缓存：`ipconfig /flushdns`
- **验收标准**：www 不再解析（而不是继续返回 404）

> 把话说透：删或不删，`www` 都是打不开的。删除的收益是**消除歧义**（不再留下"解析正常却 404 / 证书报错"的误导状态）与**去掉一个指向第三方平台的悬空 CNAME**，不是"修复了某个故障"。

## 四、不要做的三件事

1. ❌ **保留「能解析、打不开」的 www 记录**——比没有记录更糟，巡检或核查时被判定为「网站无法访问」。
2. ❌ **为绑 www 而解绑 apex**——小程序 `miniprogram/config.js` 的 `BASE` 与备案号页脚都指向 apex，会直接打挂线上。
3. ❌ **把云托管的自定义域名从 apex 换成 www**——同上，且要重走证书与域名配置，风险远大于收益。

## 五、对小程序与备案的影响

- 小程序端**完全不涉及 www**：`miniprogram/config.js` 的 `BASE` 为 `https://tdyylung3d.cn`，公众平台服务器域名也只需配 apex。
- 备案号页脚 `陕ICP备2026023325号-2` 挂在 apex 首页，与 www 无关。
- 因此**删除 www 不影响小程序，也不影响备案合规**——这正是推荐路线 A 的理由。
