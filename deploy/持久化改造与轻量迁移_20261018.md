- 编制：2026-10-18
- 背景：`/api/cases` 常为空、病例重启即丢（容器临时盘 `/app/web_output/cases`），且缩容到 0 带来 6.4s 冷启动与偶发 503
- 结论：**代码侧已完成改造**（存储位置可配置、上传暂存与产物分离、原子写），落地走「迁到已购轻量服务器」这条，本地 SSD 即为持久化

## 三、路线 A：轻量服务器执行步骤

### 现状（2026-10-18 实测）

| 项 | 状态 |
|---|---|
| 公网 IP | `82.156.160.22`（北京） |
| SSH 22 | ✅ 通（`root` 密码可登） |
| 80 / 443 | ❌ **不通**（安全组未放行） |
| 8000 | ❌ 不通（正常，本就不该对外） |
| 部署状态 | 全新机，未装 Docker / nginx |

### Step 0 · 控制台放行端口（必做，否则后面 HTTPS 打不开）

腾讯云轻量控制台 → 服务器 → **防火墙** → 添加规则：

| 应用类型 | 协议 | 端口 | 来源 |
|---|---|---|---|
| HTTP | TCP | 80 | 全部 |
| HTTPS | TCP | 443 | 全部 |
| SSH | TCP | 22 | 已有，保留 |

### Step 1 · 登录并初始化

```bash
ssh root@82.156.160.22
# 上传 deploy/lighthouse/ 整个目录到 /opt/lung3d 后：
cd /opt/lung3d
sed -i 's/\r$//' setup_server.sh          # Windows 换行必须处理，否则 bad interpreter
chmod +x setup_server.sh && bash setup_server.sh
free -h                                    # 确认 swap 2G 已生效
```

`setup_server.sh` 会做：装 Docker、建 `/data/lung3d/cases`、配 2G swap、装 nginx 并删默认站点、装 acme.sh。

### Step 2 · 准备镜像

服务器在国内，直连 Docker Hub 很慢，**推荐本机导出再上传**：

```bash
# 本机（Windows，项目根目录）
docker build -t lung3d-web:latest .
docker save lung3d-web:latest -o lung3d-web.tar
scp lung3d-web.tar root@82.156.160.22:/opt/lung3d/

# 服务器
cd /opt/lung3d
docker load -i lung3d-web.tar
docker images | grep lung3d-web        # 记下 IMAGE ID，后续以 ID 判新旧
```

### Step 3 · 配置环境变量

```bash
cd /opt/lung3d
cp .env.example .env
vi .env
```

必须填：

```ini
LUNG3D_IMAGE=lung3d-web:latest
WX_APPID=wx9bf51217a85c8560
WX_SECRET=<小程序 AppSecret>
```

`docker-compose.yml` 已预设（无需改）：`CASE_ROOT=/data/cases`、`CASE_EXPIRE_DAYS=30`、`MESH_DS_FACTOR=3`、`mem_limit 1536m`。

### Step 4 · 启动并验证持久化

```bash
docker compose up -d
docker compose logs --tail=30
# 期望看到：storage ready: backend=external path=/data/cases ... free=XXGB
curl -s http://127.0.0.1:8000/api/health
# {"status":"ok","storage":{"backend":"external","path":"/data/cases","writable":true,...}}
```

**关键验证（这一步才证明持久化真的生效）**：

```bash
# 上传一个病例，拿到 case_id
curl -s -X POST -F "files=@样例.nii.gz" -F "name=持久化验证" http://127.0.0.1:8000/api/process
curl -s http://127.0.0.1:8000/api/cases

# 重启容器（模拟升级/崩溃）
docker compose restart
curl -s http://127.0.0.1:8000/api/cases     # case_id 仍在 = 通过
ls -la /data/lung3d/cases                   # 宿主机上能看到病例目录
```

### Step 5 · nginx + 证书

```bash
# 先用手上现有证书（11-30 到期），上线后再换 acme.sh 自动续期
mkdir -p /etc/nginx/ssl
scp tdyylung3d.cn_bundle.crt root@82.156.160.22:/etc/nginx/ssl/tdyylung3d.cn.crt
scp tdyylung3d.cn.key        root@82.156.160.22:/etc/nginx/ssl/tdyylung3d.cn.key
chmod 600 /etc/nginx/ssl/tdyylung3d.cn.key

cp nginx/lung3d.conf /etc/nginx/conf.d/lung3d.conf
nginx -t && systemctl reload nginx
```

域名还没解析过来，先用 hosts 或 `curl --resolve` 验证：

```bash
curl -s --resolve tdyylung3d.cn:443:82.156.160.22 https://tdyylung3d.cn/api/health
```

### Step 6 · 切 DNS（最后一步，可秒回滚）

DNSPod → `tdyylung3d.cn`：

1. **先删**原 CNAME（`tdyylung3d.cn.tcbaccess.tencentcloudbase.com`）
2. **再添** A 记录 `@` → `82.156.160.22`

> 备案已确认「腾讯云内换 IP 无需变更接入」；且备案云资源 IP 本就是 `82.156.160.22`，切过去解析与备案资源一致。

### Step 7 · 线上验收

```bash
nslookup tdyylung3d.cn                      # 应为 82.156.160.22
curl -s https://tdyylung3d.cn/api/health    # storage.backend = external
curl -s https://tdyylung3d.cn/ | grep -o "陕ICP备[0-9]*号-[0-9]*"
# 网页端上传一个病例 → 刷新 → 列表还在
# 小程序：上传 → 查看 3D → 生成小程序码扫码直达
```

## 六、风险与注意

| 风险 | 应对 |
|---|---|
| 2核2G 处理大 CT OOM | `MESH_DS_FACTOR=3`（紧张时 4）、`mem_limit 1536m`、2G swap；`docker stats` 观察 |
| 4M 带宽首屏慢（单病例 10~30MB GLB） | nginx 已开 gzip/HTTP-2 + 7 天缓存；后续可 Draco 压缩 |
| 单机无冗余 | 每日 tar 备份；重要病例可再 rsync 到 NAS/COS |
| 50GB 盘会满 | `CASE_EXPIRE_DAYS=30` 自动清理 + 备份脚本磁盘水位告警 |
| 证书 11-30 到期 | 迁移完成后立即上 acme.sh：`acme.sh --issue -d tdyylung3d.cn --nginx` 并 install-cert 自动 reload |
